# i18n Specification

## Overview

This specification defines the internationalization (i18n) implementation for Symphony Feishu, supporting Chinese (Simplified) and English.

## 1. Architecture

```
src/symphony/
├── i18n/
│   ├── __init__.py
│   ├── manager.py          # Translation manager
│   ├── loader.py           # Locale file loader
│   └── formatters.py       # Message formatters
├── locales/
│   ├── en_US/
│   │   └── LC_MESSAGES/
│   │       ├── base.po
│   │       ├── errors.po
│   │       └── notifications.po
│   └── zh_CN/
│       └── LC_MESSAGES/
│           ├── base.po
│           ├── errors.po
│           └── notifications.po
└── ...
```

## 2. Translation Domains

### 2.1 Base Domain (base.po)
- General UI strings
- Status labels
- Common actions

### 2.2 Errors Domain (errors.po)
- Error messages
- Exception descriptions
- Debug information

### 2.3 Notifications Domain (notifications.po)
- IM notification templates
- Card content
- Progress messages

## 3. Usage

### 3.1 Basic Translation

```python
from symphony.i18n import _

# Simple string
message = _("Task started")

# With variables
message = _("Processing task {task_id}").format(task_id="FEAT-123")

# Pluralization
count = 5
message = _("{count} task processed", count=count, plural="{count} tasks processed")
```

### 3.2 Locale Detection

```python
from symphony.i18n import get_locale, set_locale

# From Feishu user profile
user_locale = await get_user_locale(user_id)
set_locale(user_locale)

# From environment
set_locale(os.getenv("SYMPHONY_LOCALE", "en_US"))
```

### 3.3 Fallback Chain

```
User Locale -> en_US (default)
```

## 6. Configuration

```yaml
# config.yaml
i18n:
  default_locale: en_US
  fallback_locale: en_US
  supported_locales:
    - en_US
    - zh_CN
  auto_detect: true  # From Feishu user profile
```

## 7. Testing

### 7.1 Translation Tests

```python
def test_translation_en():
    set_locale("en_US")
    assert _("task.started") == "Task started"

def test_translation_zh():
    set_locale("zh_CN")
    assert _("task.started") == "任务已开始"

def test_fallback():
    set_locale("unknown")
    assert _("task.started") == "Task started"  # Falls back to en_US
```

## 8. Build Process

```bash
# Extract strings
pybabel extract -F babel.cfg -o messages.pot src/symphony

# Initialize locale
pybabel init -i messages.pot -d src/symphony/locales -l en_US
pybabel init -i messages.pot -d src/symphony/locales -l zh_CN

# Update translations
pybabel update -i messages.pot -d src/symphony/locales

# Compile
pybabel compile -d src/symphony/locales
```
